# Tag 标签

标记内容的属性、状态或分类，**表达状态而非触发操作**。

## 何时使用

- 表格 / 列表中标记一行数据的状态（启用 / 待审核 / 已停用）
- 给内容打分类或属性标记（如「新品」「置顶」）
- 一组可增删的筛选条件回显

## 何时不用

| 场景                  | 应该用              |
| --------------------- | ------------------- |
| 点击标签会触发动作    | 按钮或可点击的 Chip |
| 表达数量级（如"99+"） | Badge 徽标          |
| 表单里的多选项        | 复选框 / 多选框组   |
| 需要用户输入的筛选值  | Select / Input      |

> **核心判断**：Tag 是「只读的状态陈述」。如果用户会点它然后期待事情发生，它就该是按钮。

## 可关闭与双轨显隐

与 Switch / Input 一致，显隐支持双轨：

| 传入              | 模式                         |
| ----------------- | ---------------------------- |
| `v-model:visible` | 受控，是否隐藏由外部驱动     |
| `default-visible` | 非受控，内部自持并 emit 通知 |

<demo src="./demos/tag/closable.vue" />

## 无障碍

关闭控件是原生 `<button>`（带 `aria-label="关闭"`），可键盘聚焦并用 Enter / Space 触发，不要用纯 `span` 模拟。

## 设计规范

| 项   | 规范                                                    |
| ---- | ------------------------------------------------------- |
| 用色 | 浅底深字（柔和表面 + 加深文字），不直接铺饱和色         |
| 文案 | 2~4 字的状态词，避免长句；同一列表内的状态词口径要一致  |
| 数量 | 同一行内标签不超过 3 个；更多时收纳到详情里             |
| 关闭 | 需要用户移除时才给 `closable`；展示型标签不要带关闭按钮 |

## API

### Props

| 属性           | 说明                           | 类型                                                        | 默认值   |
| -------------- | ------------------------------ | ----------------------------------------------------------- | -------- |
| type           | 标签类型；`info` 为中性灰      | `'primary' \| 'success' \| 'warning' \| 'danger' \| 'info'` | `'info'` |
| closable       | 是否显示关闭按钮               | `boolean`                                                   | `false`  |
| visible        | 受控显隐（传入即视为受控模式） | `boolean`                                                   | -        |
| defaultVisible | 非受控模式初始显隐             | `boolean`                                                   | `true`   |

### Events

| 事件           | 说明               | 回调参数            |
| -------------- | ------------------ | ------------------- |
| update:visible | 显隐请求变化时触发 | `(value: boolean)`  |
| close          | 点击关闭按钮时触发 | `(evt: MouseEvent)` |

### Slots

| 插槽    | 说明     |
| ------- | -------- |
| default | 标签内容 |

### 类型导出

```ts
import type { TagProps, TagType } from '@aura-vue/components';
```

### CSS 类名

| 类名                                        | 说明                    |
| ------------------------------------------- | ----------------------- |
| `.aura-tag`                                 | 根节点（中性灰外观）    |
| `.aura-tag--primary/success/warning/danger` | 语义色                  |
| `.aura-tag--closable`                       | 可关闭                  |
| `.aura-tag-close`                           | 关闭按钮（原生 button） |
