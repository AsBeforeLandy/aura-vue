# Steps 步骤条

引导用户完成**有明确先后顺序**的分步任务。

## 何时使用

- 注册 / 下单 / 实名认证等分步流程
- 任务需要展示「走到哪一步、还剩几步」
- 某一步可能失败并需要明确标记（如校验失败）

## 何时不用

| 场景                   | 应该用           |
| ---------------------- | ---------------- |
| 各步骤之间没有先后依赖 | Tabs / Segmented |
| 只是导航跳转入口       | 面包屑 / 菜单    |
| 一个表单内的字段分组   | 表单自身的分节   |
| 进度是连续的百分比     | Progress         |

> **核心判断**：Steps 表达「离散步骤 + 先后关系」。步骤可以乱序完成就不是 Steps；进度连续就用 Progress。

## 无障碍

组件用 `ol / li` 有序列表承载语义，当前步骤带 `aria-current="step"`——读屏用户能直接听到当前停在哪一步。圆圈里的对勾是装饰（`aria-hidden`），**失败原因要写进步骤的标题或描述文字**，不能只靠红色。

## 设计规范

| 项   | 规范                                                           |
| ---- | -------------------------------------------------------------- |
| 数量 | 3~5 步最佳；超过 5 步说明流程该拆分                            |
| 文案 | 步骤用动词短语（「确认订单」），描述写该步的关键信息或失败原因 |
| 出错 | `status="error"` 标记当前步，同时给出可操作的纠错入口          |
| 回退 | 允许点击已完成步骤回退时，组件之外自行处理跳转逻辑             |

## API

### Props

| 属性    | 说明                                          | 类型                   | 默认值      |
| ------- | --------------------------------------------- | ---------------------- | ----------- |
| items   | 步骤列表（`{ title, description? }`）         | `StepItem[]`           | `[]`        |
| current | 当前步骤下标（从 0 开始）；越界值会被钳位推断 | `number`               | `0`         |
| status  | 当前步骤的形态                                | `'process' \| 'error'` | `'process'` |

### 类型导出

```ts
import type { StepsProps, StepItem } from '@aura-vue/components';
```

### CSS 类名

| 类名                                          | 说明                      |
| --------------------------------------------- | ------------------------- |
| `.aura-steps`                                 | 根节点（ol）              |
| `.aura-steps-item--finish/process/error/wait` | 步骤状态                  |
| `.aura-steps-item--last`                      | 最后一项（不画连接线）    |
| `.aura-steps-marker / -body / -title / -desc` | 圆圈 / 内容 / 标题 / 描述 |
