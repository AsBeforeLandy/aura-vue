# Empty 空状态

列表 / 搜索结果为空时的占位，**给用户下一步动作**。

## 何时使用

- 列表、表格首次无数据
- 搜索 / 筛选无匹配结果
- 权限或状态导致的「暂无内容」

## 何时不用

| 场景                   | 应该用                     |
| ---------------------- | -------------------------- |
| 数据还在加载           | Spin，空状态要在加载结束后 |
| 请求失败               | Alert（错误要能重试）      |
| 表单页面的空字段       | 表单自身的占位提示         |
| 整页级引导（首次使用） | 专门的引导页设计           |

> **核心判断**：Empty 表达「确认没有数据」。加载中的「空」和失败导致的「空」都不能用它，否则用户会误以为真的没数据。

## 设计规范

| 项   | 规范                                                     |
| ---- | -------------------------------------------------------- |
| 文案 | 说明「为什么空」或「下一步做什么」，避免只写「暂无数据」 |
| 动作 | 每个空状态至多一个主动作（新建 / 清除筛选）              |
| 尺寸 | 占位图 96px；整页空状态可放大并垂直居中                  |

## API

### Props

| 属性        | 说明                             | 类型     | 默认值 |
| ----------- | -------------------------------- | -------- | ------ |
| description | 描述文案；不传时使用「暂无数据」 | `string` | `''`   |

### Slots

| 插槽        | 说明                           |
| ----------- | ------------------------------ |
| default     | 动作区（按钮 / 链接）          |
| description | 描述内容（优先于 description） |

### 类型导出

```ts
import type { EmptyProps } from '@aura-vue/components';
```

### CSS 类名

| 类名                                         | 说明     |
| -------------------------------------------- | -------- |
| `.aura-empty`                                | 根节点   |
| `.aura-empty-image / -description / -footer` | 内部结构 |
