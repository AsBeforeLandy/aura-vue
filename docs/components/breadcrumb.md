# Breadcrumb 面包屑

展示**当前页面在层级结构中的位置**，并提供逐级返回的入口。

## 何时使用

- 层级超过两层的后台页面（列表 → 详情 → 子详情）
- 文件 / 目录类结构的当前位置

## 何时不用

| 场景                   | 应该用               |
| ---------------------- | -------------------- |
| 扁平结构的页面         | 页面标题即可         |
| 同级内容切换           | Tabs                 |
| 记录访问历史（可后退） | 浏览器自身的前进后退 |

> **核心判断**：Breadcrumb 表达「层级位置」，不是操作历史。两层以内不需要；超过三层才体现价值。

## 无障碍

`nav` 带 `aria-label="面包屑"`，内部 `ol / li` 有序列表；**末项是当前页**：渲染为文本（不是链接）并带 `aria-current="page"`，读屏用户能明确听到「当前在这里」。中间节点只有提供 `to` 才渲染为链接。

## 设计规范

| 项     | 规范                                                   |
| ------ | ------------------------------------------------------ |
| 层级   | 3~4 层；超长用「…」折叠中间层，不要换行堆叠            |
| 文案   | 与目标页面标题一致，避免缩写                           |
| 当前页 | 永远不可点——点自己没有意义，还给用户「能否点击」的噪音 |

## API

### Props

| 属性  | 说明                                           | 类型               | 默认值 |
| ----- | ---------------------------------------------- | ------------------ | ------ |
| items | 面包屑节点（`{ label, to? }`）；末项视为当前页 | `BreadcrumbItem[]` | `[]`   |

### 类型导出

```ts
import type { BreadcrumbProps, BreadcrumbItem } from '@aura/components';
```

### CSS 类名

| 类名                       | 说明                 |
| -------------------------- | -------------------- |
| `.aura-breadcrumb`         | 根节点（nav）        |
| `.aura-breadcrumb-item`    | 节点（li，含分隔符） |
| `.aura-breadcrumb-link`    | 链接节点             |
| `.aura-breadcrumb-current` | 当前页节点           |
