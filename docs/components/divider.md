# Divider 分割线

区隔内容的分隔线，**是对内容的组织，不是装饰**。

## 何时使用

- 卡片或页面内需要按主题切分内容段落时
- 工具栏 / 按钮组中需要竖向分隔独立操作时（`direction="vertical"`）
- 带标题的分组，需要线夹住文字表达「这是标题」时

## 何时不用

| 场景                     | 应该用                    |
| ------------------------ | ------------------------- |
| 只是想让两组内容离远一点 | Space，间距是布局不是语义 |
| 卡片之间的分隔           | 卡片自身的间距 / 阴影     |
| 页面级板块的分隔         | 布局组件的区块边界        |
| 列表项之间需要分隔       | 列表组件自带的分隔样式    |

> **核心判断**：Divider 承载「这里的内容换主题了」。如果删掉它不影响对内容的理解，它就是装饰，应该删掉。

## 设计规范

| 项       | 规范                                                   |
| -------- | ------------------------------------------------------ |
| 使用密度 | 一屏不超过 3~4 条；过多说明信息层级需要重新组织        |
| 文字     | 4~8 字的名词短语，表示下方内容的主题（如「基本信息」） |
| 文字位置 | 分组标题用 left；备注 / 补充说明用 right               |
| 虚线     | 虚线表示「弱分隔」（如预览区与操作区），实线表示强分隔 |
| 垂直方向 | 只用于同一行内的并列操作之间，高度随内容自适应         |

## API

### Props

| 属性        | 说明                           | 类型                            | 默认值         |
| ----------- | ------------------------------ | ------------------------------- | -------------- |
| dashed      | 是否虚线                       | `boolean`                       | `false`        |
| direction   | 分割线方向；垂直方向不渲染文字 | `'horizontal' \| 'vertical'`    | `'horizontal'` |
| orientation | 文字位置（仅水平方向有效）     | `'left' \| 'center' \| 'right'` | `'center'`     |

### Slots

| 插槽    | 说明                         |
| ------- | ---------------------------- |
| default | 分割线文字（仅水平方向渲染） |

### 类型导出

```ts
import type {
  DividerProps,
  DividerDirection,
  DividerOrientation,
} from '@aura/components';
```

### CSS 类名

| 类名                               | 说明                         |
| ---------------------------------- | ---------------------------- |
| `.aura-divider`                    | 根节点                       |
| `.aura-divider--horizontal`        | 水平方向                     |
| `.aura-divider--vertical`          | 垂直方向                     |
| `.aura-divider--dashed`            | 虚线                         |
| `.aura-divider--with-text`         | 带文字（线条改由伪元素绘制） |
| `.aura-divider--left/center/right` | 文字位置                     |
| `.aura-divider-text`               | 文字节点                     |
